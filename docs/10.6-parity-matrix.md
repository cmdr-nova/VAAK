# VAAK 10.6 parity matrix

PHP remains the behavioral reference and write owner. Rust/Axum projections
must be read-only until their response, authorization, privacy, and mobile/API
fixtures match PHP.

| Surface | PHP reference | Rust status | Safe next gate | Write owner |
| --- | --- | --- | --- | --- |
| Home / Local / Federated | `admin_tl_*`, shared painters | Native ranked/fill paths live | response + action-bar fixture sweep | PHP / queue workers |
| Notifications | `admin_render_notification_stream` | Rust list/embed projections live | grouped actions + Ice Cubes comparison | PHP / notification queues |
| Profiles | `ap_local_profile_tab_page`, profile painters | Rust local profile HTML projection | tabs, hidden replies/boosts, quotes, asks | PHP |
| Admin health/queues | Admin stats + queue views | queue inspector shadow route | read-only health/stats projection | PHP |
| Reports/moderation | `report_*`, moderation actions | no Rust write cutover | auth, block/mute, report transition fixtures | PHP |
| Library | favourites/bookmarks/followers/following views | cache-backed fragments only | complete read-only projections | PHP |
| You | blog/RSS/queue/drafts/settings | not cut over | read-only snapshots and account isolation | PHP |
| Settings | `save_profile`, security/import/export | not cut over | field-by-field fixture + rollback suite | PHP |
| Phyrian | PHP/OpenSim bridge | dossier/read-only + guarded hand-off | origin randomness and bridge mutation parity | PHP/OpenSim |

## Required invariants

- Existing persisted settings are canonical; Rust reads must never write
  defaults over missing or unknown fields.
- Every moderation decision is owner-scoped and authoritative in PostgreSQL;
  Redis and Rust caches may accelerate reads but cannot override blocks,
  mutes, visibility, or privacy.
- Rust and PHP must expose the same object IDs, origin markers, visibility,
  reply/quote context, media, CW metadata, and action capability flags.
- Any Rust projection failure falls back to PHP without changing the URL or
  losing the user's current surface.
