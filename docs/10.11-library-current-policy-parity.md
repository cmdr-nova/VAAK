# Finite Library current-policy checkpoint — independent review pending

This phase checks the real saved-row collector, mapper and complete PHP caller
against the Rust-preferred Library renderer. It changes no production policy or
application behavior. Native flags remain off; no Git, deployment or activation
accompanies this checkpoint.

The cohort covers public, follower-granted/revoked private, direct-recipient
granted/revoked, local-member, personal and server actor blocks/mutes, muted
words, sensitive-media preferences without an overriding explicit CW, and a
public parent with a granted/revoked private quoted child. Both PostgreSQL
INTEGER and BIGINT ID widths are separate actual SQL executions. The source is
selected by genuine bookmarked/favourited rows; no expected native reply or
sidecar is manufactured. This gate uses the real PHP SQL-miss raw producer;
structured producer selection was reviewed separately.

The PHP baseline is captured independently with native rendering disabled.
Session, cached canonical lookup, worker delivery, clock and loopback transport
remain declared fixture boundaries. Canonical native hydration and ordinary
Bluesky variants are not established here. Per-request reference isolation and
the original warm, fixed-clock fixture source prevent process memo and dynamic
corpus timestamps from defining the expected output.

Each saved kind has 30 complete caller comparisons: 26 actual private-handler
HTTP 200 batches, 12 painted cards, and 14 denied roots that emit no card while
retaining the source cursor. Significant DOM, actions, raw mapper inputs,
before/after SQL, current save state, budgets and helper effects are compared.
Each has 26 malformed saved-row capability controls returning 422 with unchanged
helper intentions. Eight distinct preference checks confirm that sensitive
media stays present, with the CW disclosure only when auto-unblur is off.

Four private quoted-child cases per kind intentionally do not send a native
HTTP request: the actual shared quote-tree gate selects PHP. Their complete
caller behavior matches PHP, including denial of the revoked private child.
This preserves the existing feature, but remains missing native quote-child
coverage; it is not accepted as a Rust equivalent.

The DNS cohort invokes the actual authenticated private renderer and mutates
current SQL during eligible DNS IO, with a genuine current cached preview.
Follower/recipient withdrawals, personal/server blocks/mutes, and a new muted
word must reject publication with private/no-store 422 and no actor/media
intentions. Changing auto-unblur on an ordinary non-sensitive post is a positive
control: it safely retains one card with 200 because that setting cannot change
the card. Late-IO sensitive-media preference mutation remains open.

Failed attempts are retained in the ignored phase directory. They include the
sandbox socket denial, a duplicate rustc --test flag, omitted transitive JSON/JS
includes, a surviving mentions row, dynamic corpus timestamps, an explicit CW
that overrode the setting under test, private-child HTTP incorrectly expected,
an uncached source warming before DNS, and an unrelated setting incorrectly
expected to reject an ordinary post. Fixture corrections do not change the
production PHP oracle, policies or native admission guards.

Reproduction, immutable compiler/source provenance and exact final counts are
in `rust/target/parity-evidence/library-authority-settings-phase/HANDOFF.md`.
The binary is an ignored fixture test harness, not a production server.

Further gates remain open: real Settings action dispatch/CSRF and action-race
integration, actor aliases and domain mutations, relevant late presentation
preferences, subscription/folder actions, SQLite controller hydration, fully
native canonical hydration and private quote children, ordinary Bluesky saved
variants, cold effects, and maximum-page latency. Earlier independently
accepted saved removal/window/owner withdrawal proof is separate. Sequential
fresh policy reads are not a transactionally atomic whole-batch guarantee.
