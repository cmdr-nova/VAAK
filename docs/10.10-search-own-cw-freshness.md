# Search own content warning freshness correction

Independent actual PDO/full-Search-painter evidence confirmed a reachable warm-cache defect. A cached own status lacked a warning while its current `masto_statuses` row had edited body text, `spoiler_text='Current warning'` and `sensitive=1`. Search correctly allowed its author to see the current private note. The PHP painter refreshed the body but left warning flags in the cached entity, so the current body appeared without the CW gate. The before artifact is `/tmp/vaak-search-context-independent-cards.jsonl`: the own card contains `Current private body` in PHP output but no `Current warning` or `cw-gate`; native current-facts output contains both. This is an independently justified PHP bug correction, not a change made to accommodate a synthetic native fixture.

Only the Search branch of `admin_render_masto_status_card` changes. For the displayed own local status, the existing body lookup reads `content_text`, `spoiler_text` and `sensitive` together. Current flags replace cached flags before the canonical `cwSpoiler`/`cwSensitive` and reply action context are derived. The row lookup binds root/slash note aliases. A missing/unreadable current warning row suppresses the Search card instead of painting a potentially unfolded cached body.

The existing body rules remain: stored empty/false text and exact `(quote)`, `(media)`, `(poll)` placeholders retain the HTML-to-plain fallback; lean embeds retain their body-skip behavior while Search still refreshes warning flags. Other return views retain their original content-only query. RSS, Bluesky, remote and other users' local cards do not enter the own-row branch. An empty-body boost displayed as its own local inner status follows the same branch after canonical unwrap.

The existing `admin_cw_gate_html` remains authoritative. A custom CW stays folded even with automatic sensitive-media unblur enabled. Sensitive content without a custom CW respects the current preference; removing both flags removes the stale cached gate.

Independent reproduction/after controls are owned by the Search context reviewer: `api/bin/search-context-independent.py` and `search-context-php-independent.php` use the actual module graph and genuine PDO PostgreSQL on INTEGER/BIGINT schemas.
