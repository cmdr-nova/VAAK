## Integration contract

`profile_context::AdmittedRawProfileStatus` has private fields and no public
constructor or deserialization authority. `profile_raw::render` consumes that
token. `RawProfileFacts`, `RawQuoteFacts` and `CardFacts` are internal facts;
browser JSON must never grant ownership, guest capability or quote permission.
The pure painter performs no SQL, remote fetch, cache write or queue operation.

The context owner must supply:

- Exact current selected outbox row, its actor/key binding and MD5 DOM ID.
  PHP derives the displayed actor from the local note ID before viewer identity.
- An active authenticated owner with CSRF, or a separate trusted guest profile
  capability. Guest facts have owner zero, empty owner actor/CSRF, no own actions,
  and read-only polls retaining genuine poll IDs/counts.
- Current profile name/avatar and emoji map; the configured avatar fallback is
  `https://mkultra.monster/img/avatar/default.webp`.
- A body/CW Mastodon row when present. Own canonical interaction status ID and
  engagement counts are separate from fresh deletion/Pin local ID. Missing
  Mastodon rows can have cached interaction keys while Delete/Pin remain absent.
- Current saved flags, moderation facts, poll row and resolved Ask identity.
  Ask appears before post content/CW and excludes the stored answer from its
  question box. Missing poll rows use actual outbox `oneOf`/`anyOf` options as a
  display-only poll with no fabricated voting ID.
- Native quote presentation after recursive current-source admission. The raw
  PHP assembly's compose summary, Bluesky cache, local/event documents, cached
  status, unavailable/stub and warm/budget branches must be ported explicitly;
  shared normalized-status quote semantics are not a substitute.
- Cache-only body link card and current `masto_media.preview_url` facts. Media
  and poll output suppress the body link card. Native quote link cards remain
  noninteractive. Preserve parent/quoted media ownership and CW ancestry.
- Current clock and media loading mode; source pagination belongs to the caller,
  independently of visible or omitted cards.
