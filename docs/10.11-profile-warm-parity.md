# Profile warm effects checkpoint

`rust/vaak-worker/src/profile_warm.rs` preserves the profile actor/media warming branches from `api/ap-db.php::ap_remote_actor_warm_async` and `api/ap-r2.php::ap_media_warm_enqueue_actor` / `ap_media_warm_worker_nudge`. The caller must establish current audience/source admission before calling it and must recheck grants after awaited work. This module does not authorize a source or publish HTML.

Actor warming preserves trimmed trailing slashes, case-sensitive actor identity, case-insensitive HTTPS validation, SHA-256 lock identity, `SET NX EX 45`, and the exact `actor_id` / `ts` / `source=warm-async` payload. An unavailable Redis client or failed/contended lock returns without a PHP process. Only disabled Rust-primary mode or an acquired lock followed by failed queue publication uses the PHP process boundary. Publication uses LPUSH and EXPIRE 86400; EXPIRE failure also triggers that boundary, matching PHP rather than the existing generic helper's ignored EXPIRE error.

Media warming deliberately preserves the separate helper's case-sensitive HTTPS-prefix check. Available Redis uses a 20-second coalescing lock; unavailable Redis permits the durable SQL enqueue. The INSERT retains pending/processing rows, and only succeeded/failed rows reset attempts, next-attempt time, claimed time and error. A successful enqueue can nudge the existing worker with `--limit=3`. Feature enablement belongs to the trusted caller, as do deny-before-warm decisions.

`ProcessWarmTransport` launches the existing scripts with argv-only `nohup`, server-configured PHP/API paths, null standard streams and no shell interpretation. It uses the same temporary lock filenames and nonblocking exclusive file locks; actor process count uses bounded `pgrep -fc ap-actor-warm\\.php` and the same limit of three. Actor locks release before spawn, while media locks cover the nudge. Redis calls are bounded. These workers still depend on PHP for signed AS2 retrieval and media downloading; queue/effect parity is not proof that those workers are native Rust.
