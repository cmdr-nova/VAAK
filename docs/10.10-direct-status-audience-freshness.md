`admin_direct_status_allowed` is separate from Search and Library admission. It binds current local note existence, current remote Create/Update/quote or mention evidence, latest remote deletion state, and the existing durable audience rule. It recursively checks complete reblog/quote/preview sources, allowing harmless state-only quote descriptors without granting an unknown body. No indexing/discoverability, personal mute, muted word or server kind-mute suppression is added. Existing content-block handling remains with the controller.

`admin_direct_render_context_allowed` repeats this rule on final hydrated quote statuses and binds compact quote body/media to retained policy source or cache-only canonical lookup. It adds no signed fetch, AppView or OG requests. Unknown body authority and unavailable policy stores fail closed. Current-owner RSS quote evidence, where supplied by the canonical quote helper, remains owner-joined; ordinary foreign public AS2 mirror bodies use their ordinary source authority.

The final shared-card gate covers focused cards, explicit status/profile return contexts and the actual global `view=status` controller route. Detail actions retain their original `from`/return-view values. The global route check also covers full/partial thread ancestors and replies, whose painter action view can be `home` or `search`. Normal Search/Library discovery and saved-content gates are bypassed only within this direct scope, so `from=search/bookmarks/favourites` cannot impose indexing consent or word mutes on an explicit open. Their ordinary pages and append calls retain those gates. Legacy event fallback HTML is buffered in direct contexts and released only after its current root and final recovered quote/preview sources pass the same audience rule; a normalization refusal alone does not discard an authorized public legacy card. Other timeline fallbacks remain unchanged.
