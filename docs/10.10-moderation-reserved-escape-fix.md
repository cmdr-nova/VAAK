# Reserved URI escape correction (2026-10-10)

A fresh actual-helper review found that broad `rawurldecode` in canonical PHP actor aliases could turn `/users/alice%2F` into `/users/alice/`, then trim it into the distinct literal actor `/users/alice`. Encoded query, fragment and percent delimiters and invalid UTF-8 also require distinct identities. Native lossy Unicode decoding had an equivalent identity risk. This is a deliberate PHP baseline correction before parity acceptance.

`ap_moderation_path_segment_forms` decodes percent escapes only for ASCII unreserved bytes or a valid UTF-8 byte sequence. Reserved delimiters `%2F`, `%3F`, `%23`, `%25` and invalid UTF-8 escapes remain escaped data. The alternate encoded form encodes non-ASCII bytes while preserving retained `%XX` tokens, preventing `%2F` from becoming `%252F`. Actor-path parsing excludes literal slash/query/fragment delimiters. Existing explicit Bluesky DID colon aliases remain separate. Personal block/mute and server block path case semantics are preserved; global server mutes retain their deliberate case-insensitive comparison.

Actual positive controls also confirmed encoded unreserved numeric segments need same-path normalization: `/users/%31` and `/users/1` are equivalent URI shapes; `/@%31` and `/@1` likewise. `/users/1` and `/@1` remain distinct numeric identities. Valid UTF-8 username literal/encoded and canonical/web forms retain their existing aliases.

The rich relationship map uses the same safe segment forms, so it cannot generate a reserved-delimiter collision from its path fallback. Its rich following/follower caches use v2; bare v1 sets are unchanged. Latest compact moderation keys use personal actor blocks v3, personal mutes v4, server actor blocks v3. Owner/graph/server mutation invalidation targets exact old and current keys, never a blanket Redis flush.

`api/bin/php-policy-test api/bin/moderation-alias-cache-smoke.php` passes 91 actual-helper controls with real mbstring, isolated SQLite and deterministic Redis transport. The added controls execute all four real block/mute predicates in both stored/candidate directions for `%2F`, `%3F`, `%23`, `%25`, invalid UTF-8 versus replacement, malformed percent, numeric same/cross shape and valid UTF-8. They also execute the actual rich relationship map for distinct reserved identities. Library admission remains 61 passing actual-helper cases. Full native/PHP comparison and fresh independent cache-reader review remain required. No production change, commit, deployment or cutover is part of this fix.
