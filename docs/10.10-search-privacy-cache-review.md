This stage uses actual canonical PHP Search cache/run logic, sanitizer, filters and complete final Search painters. `api/bin/search-cache-privacy-independent.php` loads the actual declarations through the existing reference extractor. It renames the Search runner and suppresses only its redundant `require_once` bootstrap IO to avoid redeclaring dependencies already loaded by the canonical painter corpus. Hashtag scans, entities and painters execute their actual source functions without a fake tag provider. Genuine mbstring is required through `api/bin/php-policy-test`.

The database and all policies are isolated. The original painter profile fixture declares preference columns TEXT; the reviewer restores production-like INTEGER affinity for `indexable` before executing the actual FTS comparison. Cache queries have random unique names, use the actual disk cache and remove only their own keys. No external requests or production account writes occur.

## Observed defects before remediation

An author with `indexable=false` can search their own post through the canonical FTS author exception. Warming the globally shared `mf2` hashtag-query bundle as that author then reading it as another user returned the same post and complete visible body, although the second user's fresh actual FTS query returned zero hits. The reverse order also caused an omission: another user warmed an empty bundle, and the author received no card despite a fresh current FTS hit. Owner separation is necessary for both privacy and existing author-search behavior.

On a previously warmed legitimate public post, withdrawing `indexable`, changing the current outbox audience to private, revoking an accepted follower, removing direct `to` or `cc` recipient grants, or deleting both canonical local source rows left the old body visible. Each cause is isolated: indexing is re-enabled before audience tests, a current public outbox exists before warming, and valid public source rows are restored before moderation tests. Current actor blocks and actor mutes remove warm results. Search intentionally continues to display word-muted matches; that policy is not a defect or a reason to adopt Library's stronger filtering.

An actual public remote parent with a fully embedded private local quoted source passed the old Search filters and rendered a distinct private child marker despite current recursive audience denial. Separately, actual hashtag scans returned a unique tag occurring only in another author's private outbox body with no viewer recipient/follower grant; the final tag painter exposed that name.
