## Changes

- Sidebar HTML is filtered each request against the current viewer. The old 30-second Redis HTML fragment is no longer read or written. Global raw trend cache data is unchanged; no extra external collection is forced.
- Read the saved `downranking_enabled` flag and current `suppressed_until` rows. Disabled temporary downranking or expired suppression does not exclude an author. Manual Deprioritize is independent, read directly from current SQL, and applies across syntactic aliases and cache-known Bluesky DID/handle aliases. Manual actor path case remains significant; the existing temporary suppression normalization is preserved.
- Retain server/personal blocks, mutes, muted words and native Bluesky hidden-DID policy. Recursively examine quoted/boosted authors (maximum depth 16; deeper candidates omitted). Guest/owner-zero candidates retain server moderation, including URI-only account identities. Suppressed/deprioritized contributors also filter tag rows. Continue scanning the raw candidate list to refill the same five eligible post slots in original order.
- `ap_masto_trend_actor_hidden` and `ap_masto_trend_item_hidden` gain an optional, default-true flag for their existing cached manual-Deprioritize check. Existing callers retain their behavior. Only the sidebar opts out of that cached manual receipt and uses current SQL policy instead, so an unmarked author is immediately eligible even when a legacy helper's manual cache remains warm.
- Resolve session identity and current suppression/manual policies **after** reading both global raw caches. A changed viewer during cache I/O refuses the old binding. Rendering is synchronous; this is a current read after cache I/O, not a transactional snapshot of every moderation write.
- AJAX responses use `private, no-store`. Browser requests use `cache: 'no-store'` and retain global candidate refresh behavior. Remove the unscoped 15-minute sessionStorage HTML replay. Every full/soft navigation and visible-page/back-forward restoration revalidates policy. Aborted, older-generation or detached-sidebar responses cannot paint; failures clear old cards. Pagehide clears the sidebar before back-forward caching. There is no timer polling or new external refresh loop.
