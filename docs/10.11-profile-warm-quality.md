## Actionable defect

`actor_key` relies on WHATWG `reqwest::Url` plus host/control checks, whereas PHP uses `FILTER_VALIDATE_URL`. Actual PHP rejects all four following inputs, while the compiled Rust URL parser accepts them and the remaining `actor_key` checks do not reject them:

- `https://remote_test/a`
- `https://é.test/a`
- `https://remote.test/a?x=é`
- `https://-remote.test/a`

Proof: actual PHP CLI `filter_var` probe and standalone Rust probe `/tmp/vaak-profile-warm-url-quality.rs` linked to the workspace's compiled reqwest dependency. Fix actor validation before treating actor enqueue/process admission as equivalent. Preserve media warming's deliberately separate prefix-only validation. Root and runtime owner were notified; runtime edits remain owned by the implementation agent.
