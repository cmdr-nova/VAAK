# Admin Home downranking native read (step A9, first part)

Rust paints the phrase list on the Home downranking admin page (`?view=downranking`): each admin-managed phrase with its category tag, its added time and its Remove form. PHP keeps the shell, the session, the admin gate, the intro text, the add and preview forms, the preview result and every vocabulary action (add, remove, preview).

Admin only. Default off. It needs `VAAK_ADMIN_READ_NATIVE=1` and `VAAK_ADMIN_READ_SECRET` plus `VAAK_ADMIN_DOWNRANKING_NATIVE=1`, in both `www.conf` and `vaak.env`. When the native body arrives, PHP skips its vocabulary query.

## What it does

`ap_admin_native_read_body('downranking')` posts the usual admin envelope with offset 0 and no selectors. The worker requires a current active administrator before and after a READ ONLY transaction and runs PHP's query, `ORDER BY category ASC, phrase ASC`. `phrase` is UNIQUE, so that order is total and both sides read it from the same database collation. The Remove form carries the session CSRF token from the envelope.

Rows are `{id}` for at most 1000 phrases. The bridge validator rejects any other key, a non-positive or non-int id, and a repeated id.

Renders the PHP list instead when: the table is missing (PHP shows its migration notice), a `created_at` is in a format `relative_time` is not proven on, printed text matches the `ap_fix_utf8` mojibake pattern that `h()` would repair, there are more than 1000 phrases, or the session is not a current active administrator.

## Parity check

`api/bin/admin-downranking-native-review.php` (sandbox only) runs the genuine vocabulary query and phrase list template with the genuine `relative_time` and `h`, and compares whitespace-collapsed HTML in full and shell modes. The fixture has HTML and quote characters in a phrase and a category, mixed-case phrases, emoji and accented text, a disabled phrase (PHP lists it too), a future time, a zoneless time, and an empty table. Fallbacks: every case listed above, plus ordinary, disabled-admin and unknown accounts, a nonzero offset and a filter selector.

2026-10-21: 33/33 checks with INTEGER ids and 33/33 with BIGINT ids.

The Downranked review page is the second part of A9. Its list read runs a cleanup DELETE of expired and local signals first, which stays in PHP before the native read.
