Finite repair against deployed `bc6079a` (0.8.34); uncommitted and undeployed. This closes a bounded PHP publication/display defect, not full Rust parity.

## Actual failure and repair

The ordinary AJAX composer directly calls the local reply wrapper and `ap_publish_status_text`; it does not first publish through `ap_action_queue`. The status/outbox/compose event are saved before federation delivery is durably queued. Successful delivery-queue enqueue returned before the existing author Home/Local fanout, while compose events were excluded from the ordinary public follower/discovery fanout.

The existing author fanout now runs once after durable save and before that return, best effort with a generic failure log. Author Home retains own visibility; Local fanout remains public only. Public local compose events join the existing follower/public fanout guards. Synchronous missing-queue fallback does not repeat the author fanout. No new remote hydration or federation network call is on this path.

Successful composer JSON exposes canonical note ID and publication time. Composer refresh waits for an in-flight poll, explicitly requests fresh current SQL, overlaps the publication second, and inserts without losing the scroll anchor. Current node/view/generation guards reject navigation races. Detached or unsupported surfaces request the existing page reload path.

Fresh PHP Home/Local newer selection includes same-second durable own sources and public peer compose events. Local outbox selection explicitly retains its discovery visibility guard. PHP self-replies use the actual shared status/media/actions painter for both visible local segments. Home compose events are resolved back to their current outbox source, because their event painter otherwise bypassed that grouping. Both segment sources undergo current audience/moderation/discovery checks before and after painting. Hidden parents yield an ordinary visible reply rather than leaking an ancestor.

Browser reconciliation keys a thread by its tip, deduplicates pending cards, and replaces an already painted standalone ancestor only at insertion. New raw selected source counts are separate from painted wrapper counts: a selected parent plus selected reply can consume two source positions while painting one wrapper. A fetched off-page ancestor contributes no selected source position.
