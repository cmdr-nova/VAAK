### Undo and original-note lineage correction

Actual PHP Undo writer controls exposed that deleted Announce/Quote/QuotePost interaction rows can share an original note target URI. Native Search and Library liveness now ignore Announce/Like, and ignore Quote/QuotePost target events whenever Create/Update note lineage exists for that URI. Latest note Delete/Tombstone and deleted Create/Update still withdraw the source; legacy quote-only sources retain their current/deleted behavior. Shared audience lookup uses the same lineage distinction, preventing a public quote interaction from replacing a private original note's author/audience. The owned actual-module INTEGER/BIGINT fixture replays real PHP writer output and checks root/slash/nested Undo positives, original deletion negatives, legacy quote-only behavior, and private-original/public-quote denial plus authorized original-author follow. Independent combined PHP caller review is still required; no native flag was enabled.
