## Boundaries verified in source

`DirectSession` and `AdmittedDirectStatus` have private fields and no request JSON
constructor or Deserialize implementation. Positive current owner identity,
current actor/key, CSRF and canonical caller intent are distinct from source
audience. Profile presentation actor is not used to grant access. Source indices
are assigned before omissions, and the admitted token binds the exact transformed
source to its current facts and presentation options.

The raw Library shared entry still accepts only bookmarks/favourites/search.
Direct has a dedicated admitted entry. Current local sources require both a
Mastodon row and an outbox note even when a live Create event exists. Direct
audiences retain explicit-open mute/word behavior; Status root block checks use
the original wrapper actor. Profile target/header admission remains a separate
producer gate. There is no blanket recursive block/mute expansion.

Original displayed cached content is retained before own plaintext refresh for
the PHP preview selector. The budget is copied into private batch state, and an
unsupported branch returns an error without publishing cards or final budget.
DNS is a transport input whose answers still execute the real eligibility
predicate. Cold, expired, rejected, failed or uncertain preview branches preserve
the whole PHP request rather than inventing HTML or compensating counters.

## Findings requiring independent correction controls

1. The supplied-card branch initially retained explicit `status: fail`, although
   the PHP painter unconditionally forces `status: ok`. This could suppress an
   otherwise renderable supplied card and consume a budget or cause fallback.
   The runtime owner corrected the branch to unconditionally force `ok`;
   actual fail/null/scalar supplied status controls are required before acceptance.
2. Final source/audience and owner checks initially preceded awaited preview
   DNS/cache work. PHP performs its final current gate after preview work.
   Withdrawal, deletion and owner changes during declared DNS transport need
   controls. Current source, audience, Status wrapper block and owner identity
   are now rechecked after preview resolution, immediately before publication.
3. Saved-origin quote fallback initially examined only the root quote field.
   A displayed empty-content boost child can itself contain a complete quote.
   The canonical saved-origin quote helper still applies Library child policy.
   Until that policy is ported, recursive represented quote detection must
   preserve whole-request fallback without expanding root block policy. A
   bounded recursive quote detector now enforces that fallback.
4. URL canonicalization initially discarded any port suffix without checking
   PHP parse-url semantics. Actual PHP selector returns null for
   `https://article.test:foo/path` and port `99999`, while port `443` and empty
   port canonicalize to the portless path. Invalid port input must fall back or
   exactly execute the PHP selection behavior, never resolve a different cached
   URL. Numeric port grammar/range validation now preserves whole PHP fallback
   on the malformed ports. These pure PHP controls were executed during this
   review.
5. An explicit null/non-string `uri` could mask the valid URL in native option
   lookup while PHP null-coalesces to the URL, causing an unintended omission.
   The private supported-tree boundary now recursively falls back for that
   shape before admission. It neither changes the absent/string URI branches
   nor modifies shared audience or painter logic. Owner targeted tests cover
   root/nested null and non-string values plus an ordinary string control.

The fifth correction is exclusively an unsupported-shape early fallback. The
prior complete normal-corpus proof remains applicable when paired with a fresh
current-module shape test and representative ordinary-source replay; an
expensive automatic full rerun is not required solely for this isolated guard.

The batch also reports whether its normalized private status budget actually
changed. A future bridge must leave the original absent or malformed PHP global
untouched when no status-budget branch changes it, and commit new integer state
only after all native cards render successfully and the strict reply validates.
