## Secret and effective SAPI design

Generate one stable private random issuer secret on the server only, at least32characters, after independent review. Back it up outside the web root in a root-private directory; preserve it indefinitely while issuance rows exist. Do not print it, put it in shell argv, sync it to the desktop, log it or rotate it opportunistically. It must be exposed identically in the actual Clearance and VAAK FPM request environments. Both currently use www, but independently confirm the pgstage pool before deciding whether to configure it too.

Original pool files were root:root0644: never put a literal secret in a world-readable pool file. A reviewed option is protected root:root0640 pool files plus a root-private canonical secret backup and identical env[VAAK_SUPPORTER_CODE_SECRET] values, written with umask0077 and atomic replacements. FPM master reads the files as root. Preserve every unrelated directive, DSN, existing native flag and original file metadata in the protected rollback backup. php-fpm8.3 -t must pass before reload. A systemd EnvironmentFile alternative requires a master restart, because reload does not import a changed master environment; do not claim reload picked it up.

A staged readiness-probe.php can be temporarily placed outside the web root in a narrowly traversable operator staging directory and executed through the Unix FastCGI socket using cgi-fcgi. It returns only booleans, never secrets, credentials, rows or connection errors. It opens a real PostgreSQL READ ONLY transaction directly, checks actual ap_users/ap_registration_applications/ap_supporter_codes presence, and opens Clearance SQLite using SQLITE3_OPEN_READONLY. It intentionally does not include application bootstrap, which can migrate and mutate. It checks actual request feature flags and secret minimum length. Identical secret must additionally be verified internally without returning a digest or value. Root has now executed this direct FastCGI probe against both actual pools with temporary files outside the web root, removed after probing.
