# VAAK alpha 0.8.35 — 2026-10-11

Navigation now keeps the current page title after RSS → Home, unread polling and history navigation. Opening a post and submitting an immediate reply preserve the document, draft and responsive scroll position. The right sidebar loads lazily and avoids redundant reply refreshes.

Local publication and self-reply reconciliation now surface durable posts promptly while retaining current audience and nested-source privacy checks. Library fixes preserve owned historical folder identities, current moderation and Settings behavior, raw pagination, and PHP-compatible Bluesky action wording and sensitive-content labels. Media warming suppresses the referrer before requests.

Supporter reward and registration approval scaffolding is included with all registration, reward and migration switches disabled. Only independently verified paid Clearance receipts can establish entitlement; no existing account is automatically awarded a badge. Current native profile grant checks use the existing indexed subject lookup without weakening withdrawal checks. No issuer secret is provisioned and registration is not opened.

PHP remains the write owner and canonical fallback. Complete native Library canonical hydration, mixed raw collection, private children and maximum-page/late-I/O acceptance, complete Search and profiles, and broader performance gates remain unfinished. The warm local canonical prototype is default-off and is not accepted as full native parity. Phyrian runtime and the proposed navigation database index are unchanged.

This release deploys only explicitly allowlisted VAAK PHP files and the optimized worker. Main-website and Clearance changes, internal docs, replay fixtures, credentials and Rust source are excluded. Current integrated source/build checks and the independently reviewed finite behavior evidence are retained separately; no claim of full Rust parity is made.
