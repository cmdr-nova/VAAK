# Native Admin Invites + Approvals: finite candidate pending review

Scope: actual native read bodies for Invites and default-off Approvals. PHP retains sessions, outer chrome, all mutations, CSRF and action routing. Users and the remaining Admin pages are queued separately. No configuration activation, registration launch, commit or deployment.

The private loopback endpoint requires a server secret and strict typed selectors. It queries explicit safe fields in a PostgreSQL READ ONLY / READ COMMITTED transaction, checks the current active administrator before and after reads, commits and rechecks outside the transaction, then paints synchronously without further I/O. Applicant credential hashes are excluded from query/model/response. PHP rechecks the bound current session and current role before accepting the response, and rejects wrong bindings/fields. Response streaming is capped at 2MiB. Route responses and the unchanged PHP controller are no-store.
