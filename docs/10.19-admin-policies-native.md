# Admin Policies native read (step A5)

Rust paints the Admin > Policies body: the Privacy Policy and Code of Conduct editors and the server rules textarea. PHP keeps the shell, the session, the global CSRF injection, the three saves (`policies_save_privacy`, `policies_save_conduct`, `policies_save_rules`) and the public /vaak/privacy/ and /vaak/conduct/ pages.

Default off. It needs `VAAK_ADMIN_READ_NATIVE=1` and `VAAK_ADMIN_READ_SECRET` (shared with the other Admin pages) plus `VAAK_ADMIN_POLICIES_NATIVE=1`, in both `www.conf` and `vaak.env`.

## What it does

Same envelope and protections as Relays (`10.19-admin-relays-native.md`): `view: "policies"`, offset 0, no search, current active admin rechecked around a READ ONLY transaction, bridge rechecks shape, binding and role. It reads both `ap_instance_docs` rows and `ap_instance_rules` ordered by sort order then id, and follows `ap_instance_doc_get` / `ap_instance_rules_list`: an empty or "0" title shows the default name, rules are PHP-trimmed and blank ones skipped, "Updated …" shows only for a non-empty, non-"0" timestamp. Textarea bodies are copied exactly.

The built-in default texts stay in PHP. A missing privacy or conduct row, or no non-blank rules, renders the PHP page, as do more than 100 rules, a non-admin, a disabled or revoked admin, and any bad reply.

## Parity check

`api/bin/admin-policies-native-review.php` (sandbox only) renders the genuine Policies branch against seeded PostgreSQL and compares it with the worker reply. Whitespace runs are collapsed outside textareas; the three textarea bodies must match byte for byte. The template's `require_once` of ap-instance-docs.php is replaced by the genuine extracted declarations. Cases: plain, escaping (quotes, tags, CRLF, tabs, leading newline, "0" timestamp and title, unordered/blank/null rules), null title/body/timestamp, and 100 rules in reverse sort order, each in full and shell mode. Fallbacks: missing privacy, missing conduct, no rules, blank-only rules, 101 rules, ordinary user, disabled admin, revoked admin, wrong token, offset selector.
