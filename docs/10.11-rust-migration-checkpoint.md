## Admin and Settings cutover steps (added 2026-10-19)

Same pattern as Search (steps 12-13): Rust paints the read body behind its own default-off switch, PHP keeps the shell, sessions, CSRF and every mutation, and any native refusal renders the PHP page unchanged. Each switch is flipped only when Valerie says go, one step at a time.

**Who can see what.** Admin pages are server-wide and stay behind `$vaakAdminOnlyViews` / `$vaakAdminOnlyActions` plus the native current-admin recheck before and after reads. Settings, Security and Import / Export belong to every account and are scoped by the session owner, never by an admin check. Checked on 2026-10-19: every entry in both admin lists is server-wide. The only operator-only actions on the user-facing Security page are `set_app_password` and `purge_oauth_tokens` (server-wide token purge); `change_password`, 2FA and `revoke_oauth_token` stay per user. Home downranking terms are server vocabulary; the per-user downranking toggle lives in Settings. No user feature sits behind an admin gate.
