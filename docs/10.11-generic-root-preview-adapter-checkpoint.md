## New adapter contract

Requests require integer `protocol_version: 1` and signed integer
`status_preview_budget`. PHP computes the effective integer without changing
the original global: integer values, including negatives, are retained;
absent or noninteger values have an effective budget of three.

Library replies have exactly `ok`, `protocol_version`, `source_count`, `cards`
and `status_preview_state`. Every card has exactly `source_index` and `html`.
Original source indices are assigned before binding, hydration and omission;
typed indices survive admission without comparing JSON identifiers or hashes.
The public Library admission API remains available. The shared audience mask
uses the same bounded current SQL and tree decision engine as the existing
filter; existing stamping semantics remain unchanged.

Search retains `source_counts`, `accounts`, `hashtags` and indexed `statuses`,
and requires the same version and state fields. State has exactly `initial`,
`remaining` and `attempts`. For a positive initial budget, remaining equals
initial minus actual attempts; attempts cannot exceed the source count or
initial budget. Nonpositive integers remain unchanged with zero attempts.

PHP validates all fields, types, source counts, indices and cards before
publishing HTML or committing state. Untouched state preserves the original
global's presence and type. Missing state, unknown fields, malformed later
cards, transport failures and replies over 8 MiB preserve whole-PHP fallback.
Original invalid UTF-8 sources are rejected before transport encoding.

Resolved previews are privately bound to admitted source/facts tokens. Source,
audience and exact actor/key are rechecked after awaited DNS. The batch identity
check also covers zero cards. No caller JSON field supplies action grants,
permission decisions, DNS answers or rendering clocks.

Bsky/RSS root or nested protocols, non-string explicit URI shapes and
uncertified identity scalar shapes preserve whole-PHP fallback. Library's
original ingress omissions retain their measured early no-budget behavior
from the genuine public-withdrawal 210 cohort. New current Own/Ask word and
final pre-preview omissions conservatively fall back. Search audience-passing
freshness omissions fall back because genuine full/soft Search can perform
ordinary preview work before final omission. Private Direct's late-state
proof is not assumed to establish other caller behavior.
