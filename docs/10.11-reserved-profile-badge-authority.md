Admin and Supporter are account authority badges, not selectable flair. Settings excludes both keys for every account, including the operator. Saving a profile strips reserved input before the six ordinary flair slots are normalized, then derives Admin from the current active `ap_users.is_admin` role and Supporter from the current consumed paid reward. Neither badge can be awarded by a forged form, JSON/stored flair, an old profile cache, or merely naming the actor `cmdr_nova`. Role/reward withdrawal and disabled accounts suppress the badge on current reads, including a cold account with no stored profile row. This changes displayed badges only; it grants no administrative permission or paid entitlement.

Both derived badges coexist with six ordinary slots. An explicit null or empty badge field clears ordinary flair; an omitted field preserves it.
