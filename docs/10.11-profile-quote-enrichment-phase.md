# Native quote enrichment phase

This is private, uncommitted staging. It does not register a public route or enable a replacement. Full Library/Search/profile parity remains the larger task.

The isolated modules are `profile_quote_warm.rs`, `profile_preview_fetch.rs`, and `profile_preview_transport.rs`. `CurrentQuoteGrant` is shared across quote warming and previews. Its implementation must bind the current admitted parent, exact selected source/ordinal, quote projection dependencies, owner and audience. A missing child can use an admitted parent/source grant to choose lawful pending chrome; a denied private child must never enter enrichment. A cached card, miss marker, URL alias or URL shape supplies presentation and suppression information only.

Every awaited SQL, DNS, Redis, HTTP body chunk and process boundary checks the current grant before and after the await. A withdrawal fails the complete native request. A successful earlier queue/process effect is not represented as reversible; caller HTML and budget state remain unpublished until its final complete-batch validation.

`QuoteWarmContext` distinguishes a recent miss file (1800 seconds) from the AP worker's exclusive file lock/cooldown (90 seconds), preserves PHP object lookup aliases, and chooses the owner-scoped Bsky queue branch. Handle resolution in the quoted URL conversion uses PHP's public owner-zero resolver; it does not borrow the configured Home owner or another user's Bsky credentials. Queue payloads carry the already admitted caller owner, including guest zero. Signed AP and AppView worker fetching remain existing PHP worker dependencies. Native dispatch is distinct from native worker delivery.

`PreviewFetchContext` implements current cache lookup, ordinary OG metadata, YouTube oEmbed/fallback, Mastodon card projection, success/failure cache TTLs and PHP's metadata URL cache key. The requested URL and the OG canonical URL can differ; writes preserve that existing behavior. The transport manually follows at most five redirects after the initial request, checks each logical destination, limits each body, disables automatic redirects, and retains provider circuit/probe behavior. Logical DNS validation and the HTTP client's connection resolution remain separate, matching the existing PHP policy; the evidence does not claim stronger DNS pinning.

Cache dates written by PHP are RFC3339. The native reader also supports RFC2822 and legacy SQL timestamps. Other PHP `strtotime` grammars fail the complete native request defensively; they are not assumed permanently fresh. This is an explicit defensive legacy-cache fallback, not an ordinary cold-preview feature fallback.

The PHP quote painter first checks cache without fetching. On a miss it normalizes a non-integer/absent quote budget to 2, then consumes a positive budget for the second resolver call. A zero/negative integer budget still reaches the cold URL warm helper. A cache hit or media/card branch leaves the original raw budget type untouched. The PHP consumer must commit the raw-to-integer change only after a complete validated native reply. Separate captured raw controls cover null, false, true, string `"3"`, float `3.0`, `[]`, and `[3]`.
