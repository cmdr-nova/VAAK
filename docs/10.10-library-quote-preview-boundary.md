The unchanged PHP painter therefore owns cached preview features and its existing preview budget/fetch/warm behavior. ## Library step 3

Plain quote text and cached or YouTube preview cards inside a Library quote are now painted by the native Library renderer, still only when `VAAK_LIBRARY_NATIVE_RENDER` is on. Search keeps `ap_native_quote_requires_php`. A quoted URL that is not cached and is not a YouTube watch URL still returns the whole batch to PHP, which fetches and warms. Cold status stubs, unavailable non-status targets, deleted quoted bodies, and compact Bluesky previews that already have text or media are painted without that fetch. The quote-preview budget is separate from the root status preview budget and is committed only when a plain quote actually consumed an attempt.
